Mystery Quest — Scoreboard Audit & Verification

Scope: Mystery Quest scoring only. Cook & Create and every other game were not modified. Generated as part of the scoreboard alignment with the final scoring spec.

A.Executive Summary

The final leaderboard previously ran a separate "Equal-Chance" model that recomputed every player's score at game-end and overwrote the per-action points earned during play. The scoreboard has now been rebuilt so the per-action running total is the final score, with the final-accusation deltas (+60 / −20 / +80) applied on top — exactly matching the spec.

C.Admin Panel Audit

  • Before: the activity "Scoring" card exposed only the Equal-Chance subset (Role Goal, Cooperation, Lie Detector, Clue Room, Final Accusation + two penalties) and every field was editable.
  • Now: all 13 scoreboard rules are displayed in a single read-only reference table. Every value field is disabled + readonly, so admins can view but not change them.
  • Backend protection: all scoring-point fields were removed from store() and update() validation in ActivityController. The controller saves only its validated keys, so a scoring value can never be set — not from the form, not from a crafted POST. Existing values are preserved.
  • Authoritative values: ensureMysteryQuestScoreboardValues() runs on API boot and sets the mystery-quest activity's scoring columns to the spec values, so the read-only numbers and the backend scoring always agree.
  • Untouched: timers, the Lie Detector enable toggle, and all non-scoring settings remain fully editable.

F.Final Conclusion

  • Already working (6): investigator question (+10), lie-detector start (+5), answer timeout (−10), and the believable/suspicious/lie-detector votes (+10, once per round).
  • Was missing / wrong, now fixed (7): answering a normal question (+10), fail-to-vote (−10), clue-room open (+10), and the three final-accusation outcomes (+60 / −20 / +80) — which previously ran through a different model that discarded the in-game points.
  • Core architectural fix: the final leaderboard no longer overwrites the per-action running total; the spec scoreboard is now the single source of truth.
  • Remaining: a full live play-through is the one item left to confirm in a running game (NOT RUNTIME VERIFIED above).
